# Décisions

Un fichier par décision importante : choix d'architecture, ajout d'une
dépendance structurante, alternative écartée. Tu y trouves **pourquoi** le
projet est comme il est.

- **Avant un choix du même type**, lis les décisions existantes. Ne reviens pas
  sur une décision sans en parler à l'humain.
- **Pour une nouvelle décision**, copie `0000-template.md` en
  `NNNN-titre-court.md` (numéro suivant) et ajoute-la dans la PR concernée.
- **Une décision ne se modifie pas.** Si elle change, écris-en une nouvelle qui
  la remplace, et passe l'ancienne au statut `Superseded by NNNN`.
